# Waiting Room UI

This doc describes the waiting room UI and its functionality.



## UI

There are a few components in the waiting room UI:

- Players' Seats: In the middle of the screen, it shows players' names if any exist. If a seat is empty, a player can click to take the seat. It includes:
  
  - Player A's seat: on the left
  
  - Player B's seat: on the right

- Spectator list: On the right of the screen, it lists the spectators in the game. A player on the Players' Seat can click it to become a spectator. It allows showing 6 players.

- Start Game button: Only visible to the host player. At the bottom of the game, the host can click it to start the game. It is enabled only when both Players' seats are taken.

- Close room button: Only visible to the host player. At the bottom of the game, the host can click it to close the room. All players will be kicked.

- Leave button: Only visible to players who are not the host. At the bottom of the game, a player can click it to leave the room.

- Room Configuration: At the top of the screen, it shows the game setting. The host can edit it. More details to be confirmed.
  
  - Host's name: editable only before the room open
  
  - Player capacity: editable only before the room open
