# Adventurer Skills

This document describes the Adventurer Skill system. It explains which skills an Adventurer should have and how they affect the game.

Read .docmanual/battleField/unitInformation/unitSkills.md to get the basic concept of Unit Skills that are allied to all Units. If you need to know what exactly the skills are, find the codex referenced by the unitSkills.md, but avoid transverse if possible.

## Skills Combination

For Adventurers, the Move Skills, Attack Skills and Active Skills are typically class-restricted. A unit of a certain class can only acquire these 3 types of skills of that class or the prerequisite classes.

Every Base Class has a fixed Move Skill and Attack Skill called Basic Skills, which are described below. Some classes also have some passive skills.

It is common for a class to have the skills of its Prerequisite Classes.



For the four base classes of each class tree, they are defaulted equipped with the following skills:

- Guard: SMA10001, SAA10001, SPA1001

- Brawler: SMA10002, SAA10002

- Scout: SMA10003, SAA10003, SPA10002

- Acolyte: SMA10004, SAA10004
