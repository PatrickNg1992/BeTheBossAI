# Adventurer Actions

This document describes the Adventurer actions, including the turns, action tags, skills and action behaviours.

## When adventurers take Actions

Adventurers do count down in charging time. The countdown is called *Action Countdown*. The Action Countdown is stored and displayed as an *Action Tag* in the time board display and unit display.
