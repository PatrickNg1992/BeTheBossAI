# Codex Index

This codexList folder maintains lists of collectable objects of different kinds. There are subfolders in this folder. Each corresponds to a type of collectable object. Some have sub-categories, which are presented as subfolders. Each subfolder has an index.md explaining the format and key points for that type. **Only Read them if your tasks need to work with collectable obects.** The document volumes are large. Every collectable object has a reference ID. Sort the objects by Reference ID. Check the format to locate it fast.

The following list tells you what kind of collectable objects are here and their folder:

- Unit Skills: ./skills
  
  - Move Skills: ./move
  
  - Attack Skills: ./attack
  
  - Active Skills: ./active
  
  - Passive Skills: ./passive

- Adventurer Classes: ./classes
