# Testing Scene

The game has two testing scenes.

- Test Menu

- Test Battlefield (Demo use)



## Test Menu

The test menu lets testers choose whether to start a single-player/multiplayer game.

The tester needs to start two instances to test multiplayer mode.

There should be (at least) three buttons:

- Single player mode

- Run as host

- Connect to host

## Test Battlefield

The test battlefield is a demo field, the same as the normal battlefield.
