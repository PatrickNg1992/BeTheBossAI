# Game Scenes

This md file lists all the main game scenes and is still being edited. It also introduces what the game scenes are supposed to do.

The scene may get renamed later.

## Menu

The page the players see when they open the game. It allows them to select which scene they would like to go.

## Battlefield Scene

The main scene of the game. The player battles and plays a stage here.

Check: ./battlefield folder

## Multiplayer Scene

The scene that players will see if they choose to have a multiplayer game. It controls the connection logic of multiplayer games. It includes a few sub-scenes including the waiting room. It will load the Battlefield scene once ready.

Check: ./multiplayer folder

## World Map Scene

Allows the player to select stages.

## Codex Scene

Records what the player has met before and lets them recall it. Like an illustrated book.

## Deck-editing Scene

Lets the player prepare decks for battle.

## Training Scene

Allows the player to bring up his monsters and skills.
