# Game Scenes

This md file lists all the game scenes of the game and is still being edited. It also introduces what the game scenes are supposed to do.

The scene may get renamed later.

## Battlefield Scene

The main scene of the game. The player battles and plays a stage here.

Check: ./battlefield folder

## World Map Scene

Allows the player to select stages.

## Codex Scene

Records what the player has met before and lets them recall it. Like an illustrated book.

## Deck-editing Scene

Allows the player to prepare the decks for battle.

## Training Scene

Allows the player to bring up his monsters and skills.
