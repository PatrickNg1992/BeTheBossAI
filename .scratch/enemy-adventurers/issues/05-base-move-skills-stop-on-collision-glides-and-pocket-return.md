# 05 — Base Move Skills (`SMA10001..10004`), Move Glide Logic (`Adjusted Target Position` Spiral Search), Codex Item Scripts (`src/codex/`), and Pocket Return Lifecycle

**What to build:** Phase 3 (`All Move Skills` using the **Move Glide Logic**) and Phase 4 (`Pocketed Units Return`) in `AutoFightManager` and `PresentationManager`, the `src/codex/skills/Skill_<ID>.gd` and `src/codex/classes/Class_<ID>.gd` codex script layout, and the separated Boss vs. Adventurer Pocket Area return lifecycle. In the Move Skill phase of `Action Time`, all on-table acting units that did not trigger a `Skip Movement` skill evaluate their Move Skill in `SPD` descending order (tie-broken by game order). All distance checks in Move Skills are measured **centre-to-centre**. Each Move Skill's effect determines a raw **Target Position**, and then resolves an **Adjusted Target Position**: if the Target Position is a **Valid Position** (not on a Pocket Area, inside the table without overlapping Cushions, and not overlapping another puck or obstacle — using the **Adjusted Target Position** instead of the original position for any puck that shall move), it uses it; otherwise it searches up to 3 concentric circles around the Target Position (`Distance = 0.5, 1.0, 1.5`, starting from a random `Angle` on the table plane and stepping $45^\circ$ clockwise 8 times per circle = 24 candidate points; if none is valid after 3 circles, the move is cancelled). The puck then glides toward its **Adjusted Target Position** at constant speed with its collider disabled during the movement. After all on-table acting units finish moving, any surviving pocketed Adventurers whose `Action Countdown` reached `0` return to the Cue Table at a random empty, non-pocket Tile inside the middle 80% of the table in `SPD` descending order (which **consumes their action for that turn** and skips `SPA10004 Chanting` increment), while a surviving pocketed **Boss Monster** instead respawns at the end of **that turn's `Settle Time`** so the game can always continue. In Multiplayer 2-Player Versus mode, the Host synchronizes all `Action Time` skill effects, glide destinations, and pocket returns to all Peers.
