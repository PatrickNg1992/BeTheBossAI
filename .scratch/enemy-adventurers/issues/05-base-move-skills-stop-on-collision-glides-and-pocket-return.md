# 05 — Base Move Skills (`SMA10001..10004`), Unit-by-Unit Stop-on-Collision Glides, and Pocket Return Lifecycle

**What to build:** Phase 3 (`All Move Skills`) and Phase 4 (`Pocketed Units Return`) of `Action Time`, plus the separated Boss vs. Adventurer Pocket Area return lifecycle. In the Move Skill phase of `Action Time`, all on-table acting units that did not trigger a `Skip Movement` skill execute their Move Skill **unit by unit** (one puck completes its glide before the next unit in `SPD` descending order starts). All distance checks in Move Skills are measured **centre-to-centre**. A gliding puck moves at constant speed and **stops its glide immediately upon colliding with another puck or a Cushion** (without applying impulse or collision damage), and never enters or comes to rest on a Pocket Area. After all on-table acting units finish moving, any surviving pocketed Adventurers whose `Action Countdown` reached `0` return to the Cue Table at a random empty, non-pocket Tile inside the middle 80% of the table in `SPD` descending order (which **consumes their action for that turn**), while a surviving pocketed **Boss Monster** instead respawns at the end of **that turn's `Settle Time`** so the game can always continue. In Multiplayer 2-Player Versus mode, the Host synchronizes all `Action Time` skill effects, glide positions, and pocket returns to all Peers.
