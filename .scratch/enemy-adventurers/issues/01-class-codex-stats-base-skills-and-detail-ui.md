# 01 — Class Codex Registry (`ACG10001..ACA30004`), `Lv 5` Stat Scaling (`HP / POW / SPD`), Base Skill Loadouts, and Unit Detail Display UI

**What to build:** the Class Codex registry and Unit Skill data hierarchy for all 28 Rank 1–3 Adventurer Classes across the four Class Trees (`Guard`, `Brawler`, `Scout`, `Acolyte`), wired into unit registration and the Unit Detail Display popup. Each class defines its Reference ID (`AC[GBSA][123]\d{4}`), Class Tree, Rank (`1..3`), `From` prerequisite class, default `puck mass`, `puck radius`, fixed `Action Countdown` (`4` for Guard and Brawler trees, `3` for Scout tree, `6` for Acolyte tree), Base Skills (`SMA10001..10004`, `SAA10001..10004`, `SPA10001`, `SPA10003`), and linear stat growth formula `{base HP}/{base POW}/{base SPD} + {HP/lv}/{POW/Lv}/{SPD/Lv}` (`stat = base + Lv * per_lv`), inheriting unspecified properties and Base Passive Skills from its `From` prerequisite chain. Demo battlefield Adventurers (in both Single-Player PvE and 2-Player Versus) default to **Unit `Lv = 5`** and **Skill `Lv = 1`** with all base skills equipped, and demo Boss Monsters use **`POW = 400`** for testing. Clicking an Adventurer on the Unit Information Board opens the Unit Detail Display showing its localized Class name, Unit `Lv`, numeric `HP / Max HP`, `POW`, `SPD`, `Mass`, `Radius`, `Action Countdown`, and equipped Skills (with Skill `Lv`, description, ratio/distance, and `Skill Countdown`). Pause for human UI verification of the updated Unit Detail Display.
