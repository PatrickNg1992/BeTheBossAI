# 01 — Class Codex Registry (`ACG10001..ACA30004`), `UnitSkillManager`, `Lv 5` Stat Scaling & Buff Pipeline, Base Skill Loadouts (`SPA10001..10004`), and `Skill Display` UI

**What to build:** the Class Codex registry, `UnitSkillManager` (with its trigger-time-to-skills lookup map and Statistic Buff/Debuff recalculation pipeline), the Unit Skill data hierarchy (`MoveSkill`, `AttackSkill`, `ActiveSkill`, `PassiveSkill`), and the two-row skill icon + hover **Skill Display** UI inside the Unit Detail Display. All 28 Rank 1–3 Classes (`ACG10001..ACA30004`) register their Reference ID, Class Tree, Rank (`1..3`), `From` prerequisite class, default `puck mass`, `puck radius`, fixed `Action Countdown` (`4` for Guard and Brawler trees, `3` for Scout tree, `6` for Acolyte tree), Base Skills (`SMA10001..10004`, `SAA10001..10004`, `SPA10001..10004`), and linear stat growth formula `{base HP}/{base POW}/{base SPD} + {HP/lv}/{POW/Lv}/{SPD/Lv}` (`stat = base + Lv * per_lv`), inheriting unspecified properties and Base Passive Skills from their `From` prerequisite chain. `UnitInformationDO` stores both `Lv`-scaled base stats (`base_max_hp`, `base_power`, `base_spd`) and effective stats (`max_hp`, `power`, `spd`), recalculated via `round(base_stat_at_lv * (1 + sum_pct) + sum_flat)` whenever a Statistic Buff/Debuff activates or deactivates (clamping `current_hp <= max_hp`). Demo battlefield Adventurers (1P PvE and 2P PvP) default to **Unit `Lv = 5`** and **Skill `Lv = 1`** with all base skills equipped (`Lv 5` base stats: Guard `3500 HP / 280 POW / 125 SPD`, Brawler `2800 HP / 280 POW / 160 SPD`, Scout `2800 HP / 280 POW / 145 SPD`, Acolyte `2100 HP / 280 POW / 140 SPD`), and demo Boss Monsters default to **`POW = 400`**. In the Unit Detail Display, the bottom section renders two rows of skill icons — Row 1 with 3 spaced slots (`Move | Attack | Active`, leaving an empty slot frame if no Active Skill is equipped) and Row 2 with all `Passive` Skills (plus live countdown/counter badges). Hovering a skill icon opens a **Skill Display** tooltip window showing `name`, `type`, `skill Lv`, and `Description` (never raw `Effects`) injected with resolved variable values (`?X`, `?Y` highlighted in a value colour) and `*keyword*` terms (highlighted in a keyword colour), with the meanings of those keywords listed at the bottom. Pause for human UI verification of the updated Unit Detail Display and hover Skill Display.
