# Spec: Cue Table (Battlefield)

The physical arena. Vocabulary per `CONTEXT.md` (Cue Table, Tile, Cushion, Pocket Area, Puck).

## Implementation status

Procedurally generated by `src/battlefield/battlefield.gd` (tiles, cushions, pockets) — **but the code still builds the old 20×20 square (10×10 tiles)**. The 30×20 size below is the settled design per `/doc/battleField/Battlefield.md`; updating `battlefield.gd` (constants) and `src/test_scene.tscn` (table base mesh/shape, currently `Vector3(20, 3, 20)`) is pending.

## Geometry

- Inner floor: **30 × 20** (X × Z), table height 3. Rectangular, like a real snooker table (was 20×20 square).
- Tiles: 2×2 each → a 15×10 grid. Test scene: alternating green / light green. Future: individual Tiles may carry special effects.
- Cushions: on all four sides, width 2, height above the table 2, split into 2-length segments (test scene: alternating brown / light brown). Outer rail spans: 34 on the long sides, 24 on the short sides. Corner squares: upper-left and lower-right share one colour, the other two share another.
- Cushion impacts deal no damage. **Special Cushions** (segments with triggered effects) are future work.
- Pocket Areas: hollow 2×2 zones at the four corners, replacing the corner Tiles. Damage / kill / 5s return rules: see `CONTEXT.md` → Pocket Area.
- Obstacles: TBA, future.

## Puck sizes (test scene)

Radius × height, sized by what the puck represents (large monster → large puck):

| Puck | Radius | Height |
|---|---|---|
| Boss Monster | 1.5 | 1.0 |
| Knight | 1.2 | 0.8 |
| Warrior | 1.1 | 0.7 |
| Ranger | 1.0 | 0.7 |
| Mage | 0.9 | 0.7 |

## Camera

- Fixed-side view; two on-screen buttons (left / right) move the camera to the adjacent rail side, ~1 second per move.
