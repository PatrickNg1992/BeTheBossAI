Project Name: Be The Boss

## Core Stack

* **Engine:** Godot 4.x (using GDScript with **TYPE**)
* **Genre:** 3D [Strategy, Sword and Magic, Cards, Medieval]
* **Target:** Steam

## Game Concept & Scope

The game is a 3D game with a fixed camera and a medieval theme. The player controls a boss-level Monster to defeat the incoming adventurer teams. 

There are many stages in the game world. The battles combine RPG, snooker, and Card game elements.

Side functions include Codex, training, deck composition, etc.

Now we are preparing the game demo only, which works only on one main game scene.
